# Tefillin Shel Rosh

**v0.10.0-alpha.2 — research preview.** Shared selection highlighting and received-law lessons.

## Run locally

Serve the **collection root** with `python3 -m http.server 4173` (Windows: `py -m http.server 4173`). Open http://localhost:4173 and choose Tefillin Shel Rosh. Shared modules live under `shared/`, so do not serve this artifact folder alone. All rendering dependencies are local; no build, npm install or CDN is needed. WebGL2 is required.

Choose a component to illuminate its geometry in teal. “Clear highlight” restores original material colors while keeping the lesson. On mobile, “View highlighted part” returns from the text to the model.

The overview and component cards distinguish explicit halacha leMoshe miSinai from other codified laws and customs. Direct primary-source links accompany each classification. Geometry review remains separate from source authority.

## Explore

- Drag the model to orbit. Use the wheel, pinch, or +/− buttons to zoom.
- Use Front, Rear, Top, and ¾ for repeatable viewpoints.
- Select Assembled, Exploded, or Cutaway. Reset restores the initial model, camera, Rashi arrangement, single-dalet study, and stopped rotation.
- Click visible model geometry or use the twelve component buttons. Small features remain accessible through these buttons on mobile.
- In internal views, numbered callouts correspond to the four passage buttons.
- Rashi/Rabbeinu Tam switches the identification of the passages in the fixed chamber positions. The chart always describes the front-facing viewer’s left-to-right order; camera orbit does not redefine the order.
- Selecting the rear knot or passage moves to a dedicated close-up. The single-dalet study shows a folded collar and return; the square/double-dalet option shows a four-panel outer form. Hidden interlacing remains unverified in both studies. Outer face, Reverse and Underside buttons let you inspect either study. This is not a knot-tying guide.

## What is and is not modeled

The housing has a square footprint, four elongated hollow chambers, three grooves, raised three/four-headed shins on the wearer’s right/left, a square layered base, twelve illustrative stitches, a rear strap tunnel, upright rolled passages, parchment wrappers and hair bindings, a head loop, and two descending lengths laid out for study.

Exploded mode lifts the **joined housing** above the passages and base. It does not break it into four detached boxes. Cutaway mode removes a front section of leather to make the interior visible. Both are explanatory diagrams, not real opening mechanisms or manufacturing steps.

This is an educational reconstruction, **not kosher certification or construction guidance**. Dimensions, shin calligraphy, parchment details, knot routing, and leather aging are illustrative. Both knot studies have simplified outer folds and schematic hidden crossings. No sacred writing is reproduced. Further review by an experienced sofer is needed before stronger accuracy claims. Other order variants have not been invented or included.

See `SOURCES.md`, `MODEL_NOTES.md`, `CHANGELOG.md`, and `QA.md` for evidence and limitations.

## Development and verification

The collection uses Three.js 0.186.1. `app.js` owns the scene and interactions; `shared/selection.js` manages reversible material swaps; `shared/lessons.js` contains the vetted educational summaries.

With Playwright and Chromium installed, run the scripts from an empty QA working directory so historical evidence is preserved. Set `TEFILLIN_URL` to the served artifact URL. Scripts write to `evidence/` beneath the working directory.

```sh
TEFILLIN_URL=http://localhost:4173/artifacts/tefillin-shel-rosh/ node /path/to/collection/artifacts/tefillin-shel-rosh/qa.test.cjs
TEFILLIN_URL=http://localhost:4173/artifacts/tefillin-shel-rosh/ node /path/to/collection/artifacts/tefillin-shel-rosh/qa-selection.cjs
```

Additional direct-mesh, focused touch, animation and pixel-comparison checks are in `qa-review/`. Run heavy software-WebGL browser suites sequentially. The pixel checker needs Pillow and the before/selected/restored screenshots generated by `qa-selection.cjs`.

Three.js and its included add-ons retain their MIT license in `vendor/THREE-LICENSE.txt`. All model geometry and surface textures are procedural. No third-party manufacturing photographs are shipped.

The illustrative shin outlines derive from Noto Serif Hebrew under the SIL Open Font License; see `vendor/NOTO-LICENSE.txt`. They are not a sofer-reviewed manufacturing template. Reference images are not bundled.
